Privacy Policy

Last updated: June 18, 2026

This Privacy Policy explains how Guess the Language (“we”, “the Service”) handles information when you play on the web, inside Discord, or via the desktop app.

1. Summary

We collect only what is needed to run the game and optional leaderboards. We do not sell your personal data. We do not run advertising trackers in the game.

2. Information we collect

DataWhenPurpose
Display name Leaderboard / multiplayer Show your name on scores and in rooms
Quiz score & mode When you submit to the global leaderboard Public leaderboard ranking
Game settings Stored in your browser or app Language, sound, difficulty preferences
Discord user ID & username Discord Activity only Authenticate the Activity and set your display name
Server / hosting logs When you use the website or API Security and reliability (e.g. Vercel)

3. Discord Activity

When you launch the game inside Discord, we use Discord’s Embedded App SDK to authenticate you. We request the identify scope to read your Discord user ID and username (or global display name). OAuth tokens are exchanged on our server and are not stored long-term after your session. Discord’s own privacy policy applies to data Discord processes: discord.com/privacy.

4. Supabase (leaderboards)

Optional global leaderboards are hosted on Supabase. When enabled, we store your chosen display name, score, game mode, and timestamp. Leaderboard entries are publicly readable. We do not store email addresses or passwords in the game database.

5. Local storage

The web and Discord versions may save preferences (language, high scores, settings) in your browser’s localStorage. The desktop app stores similar data locally on your device. You can clear this data by clearing site data or reinstalling the app.

6. Third-party services

  • Vercel — hosts the web app and Discord token API
  • Supabase — optional leaderboard database
  • Discord — Activity platform and authentication

Each provider processes data according to its own privacy policy. We only share the minimum data required for those services to function.

7. Children

The Service is not directed at children under 13. We do not knowingly collect personal information from children. If you believe a child has provided data, contact us and we will take steps to remove it.

8. Your choices

  • Play without submitting scores to the global leaderboard
  • Choose a custom display name on the web (not in Discord Activity, where Discord provides your name)
  • Clear browser storage to remove local preferences

9. Security

We use HTTPS for all web traffic. Discord client secrets are kept server-side only. No method of transmission over the Internet is 100% secure; we cannot guarantee absolute security.

10. Changes

We may update this policy. The “Last updated” date at the top will change when we do. Material changes may also be noted in the project repository.

11. Contact

Privacy questions: GitHub or Discord.
